Install

安裝

Install

從 Chrome 線上應用程式商店安裝，之後會自動更新。

Install from the Chrome Web Store. Updates arrive automatically.

⬇ 前往 Chrome 線上應用程式商店Open in the Chrome Web Store

  1. 安裝：在商店頁面按「加到 Chrome」。
  2. 開新分頁：Dooby 會取代新分頁頁面。把工具列的 Dooby 圖示釘選起來，在任何網頁按一下就能快速儲存。
  3. 啟用同步：確認 Chrome 已登入 Google 帳號並開啟同步，且「擴充功能」的同步項目為開啟。
  1. Install: click "Add to Chrome" on the store page.
  2. Open a new tab: Dooby replaces the new tab page. Pin the toolbar icon to quick-save any page with one click.
  3. Enable sync: make sure Chrome is signed in with sync on, and that "Extensions" is included in what you sync.
