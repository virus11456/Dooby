功能

所有資料都存在你的瀏覽器裡，沒有帳號、沒有伺服器。

Spaces 與 Collections

用空間區分工作、個人、副業，再用收藏卡片把分頁分門別類。

拖曳整理

從右側「Open Tabs」把分頁直接拖進任何收藏，或按工具列圖示一鍵快速儲存。

儲存工作階段

一鍵把目前所有分頁存成一個收藏，之後隨時整組打開。

跨裝置同步

透過 Chrome 帳號內建的同步機制，登入同一個 Google 帳號的電腦自動共享書籤。

搜尋與釘選

Ctrl+K 全文搜尋所有已存分頁，重要的收藏或分頁可釘選置頂。

匯入與備份

支援 Chrome 書籤 HTML、Toby、TabMe 匯入，完整 JSON 匯出與還原，並能找出重複網址。

安裝

從 Chrome 線上應用程式商店安裝，或以開發者模式載入原始碼。

  1. Chrome 線上應用程式商店：搜尋「Dooby - Tab & Bookmark Manager」並安裝，之後會自動更新。
  2. 從原始碼：到 GitHub 下載 ZIP 並解壓縮，開啟 chrome://extensions，打開「開發人員模式」，按「載入未封裝項目」選擇資料夾。
  3. 啟用同步：確認 Chrome 已登入 Google 帳號並開啟同步，且「擴充功能」的同步項目為開啟。

隱私

Dooby 不收集、不傳送、不分享任何個人資料。分頁標題與網址只儲存在你的瀏覽器本機，以及你選擇啟用的 Chrome 同步空間。沒有外部伺服器、沒有分析服務、沒有遠端程式碼。
