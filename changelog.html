更新記錄Changelog

Dooby 每個版本的修正與新功能。從 Chrome 線上應用程式商店 安裝即可自動更新。

Fixes and new features in every Dooby release. Install from the Chrome Web Store to get updates automatically.

v1.6.7 2026-09-16 最新Latest

  • 新增新分頁固定顯示 Stocktools、Crypig 捷徑，頁尾有 SIMPLES 工具網 連結。
  • NewThe new tab page now keeps persistent Stocktools and Crypig shortcut chips, plus a small SIMPLES 工具網 footer link.

v1.6.6 2026-09-10

  • 修正展開「再顯示 N 個」時卡片不再跑來跑去。每張卡片現在固定在自己的欄位（由左到右輪流分配），展開只會把同一欄下面的卡片往下推，其他欄完全不動。
  • FixCards no longer jump around when you expand "Show more". Each card now has a fixed column (assigned left to right in order); expanding one only pushes down the cards below it in the same column, other columns stay put.

v1.6.5 2026-09-08

  • 改善版面重新整理。左邊的「空間」側欄拿掉，空間改成頁面上方的標籤列（點一下切換、滑過去可改名或刪除、右邊的 + 新增）。右邊「開啟中的分頁」可以收起成一條細欄，狀態會記住；收起後收藏卡片自動多排幾欄。
  • 改善收藏卡片改成由左到右排列並自動緊密堆疊，不會再因為空的卡片留下大片空白；空卡片本身也縮小了。
  • ImproveLayout refresh. The left Spaces column is gone; spaces are now chips above the collections (click to switch, hover to rename or delete, + to add). The Open Tabs column collapses to a thin rail and remembers it; the collections grid gains columns when it is collapsed.
  • ImproveCollection cards flow left to right and pack tightly, so empty cards no longer leave big gaps; empty cards are shorter too.

v1.6.4 2026-09-08

  • 新增設定視窗底部顯示目前版本號並連到更新記錄；滑鼠停在左上角 Dooby 標誌也會顯示版本。
  • NewThe Settings dialog shows the installed version with a link to the changelog; hovering the Dooby logo shows it too.

v1.6.3 2026-09-08

  • 修正新增書籤不再整頁重畫。之前每存一個網頁，所有收藏卡片都會清掉重建，favicon 重新載入、展開的卡片縮回去、畫面閃一下。現在只更新有變動的那張卡片，其他卡片和右側開啟中的分頁列表原封不動，展開狀態也會記住。
  • FixAdding a bookmark no longer redraws the whole page. Every save used to wipe and rebuild all collection cards: favicons reloaded, expanded cards collapsed, the screen flashed. Now only the changed card is updated; other cards and the Open Tabs list are left untouched, and expanded state is remembered.

v1.6.2 2026-09-08

  • 改善工具列變乾淨。兩顆手動雲端按鈕和 100 KB 用量條移進 Dooby Cloud 視窗的「Chrome 帳號同步」區塊；工具列只留同步狀態燈，點它就能打開視窗。功能一個都沒少，同步本來就是自動的。
  • ImproveCleaner toolbar. The two manual cloud buttons and the 100 KB usage bar moved into a "Chrome account sync" section of the Dooby Cloud dialog; the toolbar keeps only the sync indicator, which now opens that dialog. Nothing was removed, sync is automatic anyway.

v1.6.1 2026-09-08

  • 改善Dooby Cloud 視窗重新排版：帳號卡片右側直接登出，同步狀態一行帶指示燈，網頁版提示改成醒目區塊，底部只有「關閉」和「立即同步」，「刪除雲端資料」降級成小連結。
  • ImproveDooby Cloud dialog redesigned: sign-out on the account card, one status line with an indicator, the web-app hint as a highlighted box, a footer with just Close and Sync now, and "Delete cloud data" demoted to a small link.

v1.6.0 2026-09-08

  • 新增Dooby Cloud 正式啟用。按右上角帳號按鈕用 Google 登入，書籤就會存到 Dooby 自己的雲端，跨裝置同步不再受 Chrome 100 KB 的限制。第一次登入會把本機和雲端的書籤合併。
  • 新增iPad／iPhone 網頁版：toolist.cc/dooby/app。用同一個 Google 帳號登入，就能在任何瀏覽器查看、搜尋、開啟、新增和刪除書籤，改動一分鐘內同步回 Chrome。頁面裡有 Safari 書籤小工具和 iOS 捷徑的設定教學，可以從分享選單一鍵存網頁。
  • NewDooby Cloud is live. Sign in with Google from the account button (top right) and your bookmarks are stored in Dooby's own cloud, syncing across devices without Chrome's 100 KB limit. The first sign-in merges local and cloud data.
  • NewWeb app for iPad / iPhone: toolist.cc/dooby/app. Sign in with the same Google account to view, search, open, add and remove bookmarks from any browser; changes sync back to Chrome within a minute. The page includes a Safari bookmarklet and an iOS Shortcut recipe to save pages from the share sheet.

v1.5.1 2026-09-07

  • 修正從工具列的「匯入」按鈕匯入 TabMe／Toby 檔案會顯示「Import failed: Invalid import data」。之前只有「匯入書籤」對話框裡的「Import JSON」會判斷格式，工具列按鈕和「匯出／匯入」對話框只吃 Dooby 自己的備份檔。現在三個入口都會自動判斷 Dooby 備份、TabMe、Toby、Chrome 書籤 JSON。
  • 修正工具列的「匯出」按鈕會一次下載兩個檔案，而「匯出／匯入」對話框裡的「匯出成 JSON」按下去沒反應（兩個按鈕用了同一個 id）。
  • 變更匯入成功改用底部提示，不再跳出視窗；檔案不是 JSON 時會明確說明。
  • FixImporting a TabMe / Toby file from the toolbar "Import" button failed with "Import failed: Invalid import data". Only the "Import JSON" button inside the Import Bookmarks dialog detected formats; the toolbar button and the Export / Import dialog accepted Dooby backups only. All three entry points now detect Dooby backups, TabMe, Toby and Chrome bookmark JSON.
  • FixThe toolbar "Export" button downloaded two files at once, and "Export as JSON" inside the Export / Import dialog did nothing (both buttons shared one id).
  • ChangeSuccessful imports show a toast instead of a popup; a non-JSON file gets a clear message.

v1.5.0 2026-09-07

  • 新增刪除後可以復原。移除分頁、批次刪除、刪除收藏或空間之後，底部會出現提示和「復原」按鈕，六秒內按下就會把東西放回原本的位置。
  • 新增Daylight 淺色主題。免費，在主題頁面就能切換，適合白天或亮的環境。
  • NewUndo after deleting. Removing a tab, bulk-deleting, or deleting a collection or space now shows a toast with an Undo button; press it within six seconds and everything goes back to its original position.
  • NewDaylight light theme. Free, available on the Themes page, for daytime or bright rooms.

v1.4.0 2026-09-07

  • 新增繁體中文介面。整個新分頁（工具列、側欄、右鍵選單、所有對話框、設定、贊助頁、同步狀態和錯誤訊息）都有中文版。預設跟著瀏覽器語言，也可以在設定裡固定選英文或繁體中文。Chrome 商店裡的套件名稱和說明也會依語言顯示。
  • NewTraditional Chinese UI. The whole new-tab page (toolbar, sidebars, context menus, every dialog, Settings, the support page, sync status and error messages) is now available in 繁體中文. It follows your browser language by default, or pick English / 繁體中文 in Settings. The extension name and description in the Chrome Web Store are localized too.

v1.3.0 2026-09-07

  • 新增設定頁面。工具列多了齒輪按鈕，可以調整：儲存後是否關閉分頁（工具列一鍵儲存和拖曳儲存都適用）、工具列一鍵儲存要存到哪個收藏（預設是目前空間的 Quick Save）、收藏的排序（名稱、最新、最舊、分頁數）、收藏內分頁的排序（最新、最舊、標題）。釘選的收藏和分頁永遠在最上面。設定只存在這台裝置上。
  • 變更每次推送都會自動跑完整測試（真實 Chromium 裡載入套件測試同步、儲存、啟用碼、Dooby Cloud），減少壞版本上架的機會。
  • NewSettings page. A gear button in the top bar lets you choose whether a tab is closed after saving (toolbar quick save and drag-save alike), which collection the toolbar icon saves into (default: the Quick Save collection of the current space), how collections are sorted (name, newest, oldest, tab count) and how tabs inside a collection are sorted (newest, oldest, title). Pinned collections and tabs always stay on top. Settings are per device.
  • ChangeEvery push now runs the full automated test suite (the extension loaded into a real Chromium: sync, saving, activation codes, Dooby Cloud), so broken builds are caught before release.

v1.2.0 2026-09-07

  • 新增Dooby Cloud：用 Google 帳號登入。工具列多了帳號按鈕，登入後書籤會存到 Dooby 自己的雲端（Supabase），不再受 Chrome 同步 100 KB 的限制，也是之後在 iPad、iPhone 使用的基礎。第一次登入會把本機和雲端的書籤合併，不會遺失任何資料；之後的修改自動上傳，其他裝置一分鐘內更新。
  • 新增同一個對話框可以登出，或永久刪除雲端上的資料。
  • 變更新增 identity 權限，只用來開啟 Google 登入視窗。
  • NewDooby Cloud: sign in with Google. A new account button in the top bar. Once signed in, your bookmarks live in Dooby's own cloud (Supabase) with no 100 KB limit, which is the foundation for using Dooby on iPad and iPhone. The first sign-in merges local and cloud data so nothing is lost; later edits upload automatically and other devices catch up within a minute.
  • NewSign out or permanently delete your cloud data from the same dialog.
  • ChangeAdded the identity permission, used only to open the Google sign-in window.

v1.1.9 2026-09-07

  • 修正贊助者啟用碼真的會驗證了。之前只檢查開頭是不是 DOOBY-，任何人隨便打都能解鎖。現在啟用碼是開發者用私鑰對「顯示名稱」簽出的簽章，套件用內建的公鑰驗證，名稱或代碼不對就無法啟用。舊版用假代碼解鎖的狀態會在啟動時自動撤銷。
  • 修正取消啟用或啟用失效時，付費主題會退回免費的 Midnight 主題。
  • 新增開發者用的啟用碼產生工具 scripts/gen-activation-code.js。
  • 新增這個更新記錄頁面。
  • FixSupporter activation codes are now actually verified. The old check only looked for a DOOBY- prefix, so anything unlocked the perks. A code is now a signature of the display name made with the developer's private key and verified in the extension with the embedded public key; a wrong name or code no longer activates. States unlocked with fake codes are revoked on startup.
  • FixDeactivating, or losing activation, falls back from a premium theme to the free Midnight theme.
  • NewDeveloper tool for issuing codes: scripts/gen-activation-code.js.
  • NewThis changelog page.

v1.1.8 2026-09-06

  • 修正跨裝置同步永遠連不起來。未封裝載入的套件 ID 是由資料夾路徑算出來的，每台電腦都不同，等於各自有一個雲端空間。manifest 加入固定的 key，所有安裝的 ID 都是 dfoidibckihcnmakgoabkebinahggked。
  • 改善滑鼠停在同步狀態上會顯示套件 ID，方便比對兩台電腦是否一致。
  • 新增Chrome 線上應用程式商店打包腳本，以及這個網站（首頁與隱私權政策）。
  • FixCross-device sync could never connect. An unpacked extension's ID is derived from its folder path, so every computer got a different ID and its own separate cloud storage. The manifest now carries a fixed key, giving every install the ID dfoidibckihcnmakgoabkebinahggked.
  • ImproveHovering the sync status shows the extension ID so mismatches between devices are easy to spot.
  • NewChrome Web Store packaging script and this website (home page and privacy policy).

v1.1.4 2026-09-02

  • 修正雲端同步每次上傳都失敗。資料切塊原本用字元數計算，但 Chrome 的每個 key 上限 8 KB 是用位元組算，中文標題會超過。改成用位元組切塊，並修正 100 KB 總量的計算方式。
  • 修正定時同步先拉再推，避免舊資料蓋掉雲端。
  • 改善同步錯誤訊息區分「單一 key 超限」「總量超限」「寫入過於頻繁」。
  • FixEvery cloud sync upload failed. Data was chunked by character count, but Chrome's 8 KB per-key limit is measured in bytes, which non-ASCII titles exceeded. Chunks are now sized by bytes and the 100 KB total check is measured the same way.
  • FixPeriodic sync pulls before pushing so stale data cannot overwrite the cloud.
  • ImproveSync errors distinguish per-key, total and write-rate limits.
