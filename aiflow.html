01 / Mac 安裝

  1. 下載並開啟 DMG，將 AI Agent Flow.app 拖曳到 Applications 捷徑，複製完成後退出磁碟映像。
  2. 開啟 App，在「帳號登入」完成 Codex 官方登入。Claude 請在官方 Claude Code 登入，再於 AI Flow 點「連接官方摘要」。
  3. Claude Code 需 2.1.251 以上版本。完成一次對話後，官方狀態列才會提供用量。AI Flow 不讀取 Claude 鑰匙圈憑證；已有自訂狀態列時不會覆蓋，請依 GitHub 說明整合。
  4. 確認收到兩家的額度後，再設定手機同步。Claude 方案與模型專屬額度未由官方摘要提供時，不會顯示。

此版本尚未經 Apple 公證。若系統阻擋，請在確認檔案來源後，依 macOS「隱私權與安全性」提示處理；不需要停用 Gatekeeper。

02 / iPhone 與 iPad

  1. 在 App Store 安裝 Scriptable，並在 Mac 與手機使用同一個 iCloud 帳號、開啟 iCloud Drive。
  2. 下載 Scriptable 腳本，或開啟可複製的程式碼。在 Scriptable 新增腳本，貼上完整內容，命名為 AI Agent Flow。
  3. Mac App 點「設定 iPhone 同步」，選取 iCloud Drive 裡的 Scriptable 資料夾。
  4. 在 Scriptable 執行腳本，選「預覽小工具」，確認額度已同步。
  5. 長按手機主畫面 → 加入 Scriptable 小工具 → 選中型。長按小工具 → 編輯小工具 → Script 選 AI Agent Flow。

已有小工具時，更新原本腳本即可；若換了腳本名稱，也要更改小工具的 Script 選項。

更新方式與限制

Mac 每 30 分鐘查詢 OpenAI 並讀取 Claude 摘要。App 必須保持執行；Mac 關機或休眠時，不會持續取得新資料。手機目前透過 iCloud 取得 Mac 的摘要，不能獨立查詢。

iOS / iPadOS 決定 Widget 的實際刷新時間，並不保證每 30 分鐘準時更新。查詢失敗時保留上次資料；限流時會延後重試。

OpenAI 顯示的是 Codex 等工作額度，不包含一般 ChatGPT 網頁聊天額度。Claude 改讀官方狀態列的 5 小時及每週摘要。只使用網頁聊天時可能沒有新資料，摘要接收時間也不等於服務端查詢時間。

Mac 桌面可依系統支援加入 iPhone 的 Scriptable 小工具；這不是獨立的原生 WidgetKit 小工具。

常見問題

Mac 關機後，手機還會更新嗎？

目前不會。Mac 負責查詢額度，iCloud 將摘要送到手機。Mac 休眠或關機時，小工具會保留最後一筆資料，請留意顯示的更新時間。

需要在 iPhone 輸入帳號密碼嗎？

不需要。Scriptable 只讀 iCloud 用量摘要；AI Flow 也不需要 Claude 密碼或 Token。Claude 登入在官方 Claude Code 完成。

為什麼不是每 30 分鐘準時刷新？

Mac 查詢與手機小工具刷新是兩個不同步驟。手機背景執行時間由 iOS 決定，加上 iCloud 同步可能延遲，所以不保證固定時間更新。

沒有更新？

在 Scriptable 執行腳本，選「檢查自動更新」。紀錄會顯示背景執行時間、來源資料時間與讀取結果；查看紀錄不會手動刷新額度。

0.3.9 已移除 ClaudeRefresh 與直接憑證查詢。若仍看到 ClaudeRefresh 要求密碼，請確認舊 App 已結束，並從 Applications 啟動新版；官方 Claude Code 自己的系統授權仍由它處理。
