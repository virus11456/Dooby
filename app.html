方法 B：iOS 捷徑（分享選單裡出現「存到 Dooby」）

  1. 打開「捷徑」app → 新增捷徑 → 右上角資訊 → 打開「顯示在分享工作表」，接收類型只留「URL」。
  2. 加入動作「URL 編碼」，輸入選「捷徑輸入」。
  3. 加入動作「開啟 URL」，內容填：https://toolist.cc/dooby/app?add=後面接上一步的「URL 編碼文字」變數。
  4. 命名「存到 Dooby」。之後在 Safari 分享選單選它即可。

Option B: iOS Shortcut ("Save to Dooby" in the share sheet)

  1. Shortcuts app → new shortcut → info (ⓘ) → enable "Show in Share Sheet", accept only URLs.
  2. Add action "URL Encode" with input "Shortcut Input".
  3. Add action "Open URLs" with https://toolist.cc/dooby/app?add= followed by the "URL Encoded Text" variable.
  4. Name it "Save to Dooby". Pick it from Safari's share sheet.
